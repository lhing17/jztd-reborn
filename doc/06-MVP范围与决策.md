# 06 · MVP 范围与决策

> 版本：v0.1（草稿） · 2026-10-15
> 前置文档：01~05 全部设计文档；里程碑框架对照《太阳编辑器塔防AI协作开发指南》§11

## 一、MVP 完成条件（唯一标准）

> 玩家不输入任何测试命令即可完成：选门派 → 建塔 → 打完主线 → 爽到 → 奖励可靠入档 → 再开一局。

「服务和测试命令都存在」不算完成；完整单局可玩才算。

## 二、首发版本内容清单（MVP）

| 系统 | 首发内容量 |
|------|-----------|
| 门派 | 3 个：少林、武当、峨眉（各 4 弟子线 × 3 阶 + 镇派弟子，共 13 单位/门派） |
| 武学池 | 通用 10~12 张 + 门派 6~8 张/门派 + 绝学 4 张（共 ~30 张；默认解锁 15~18 张，**名望锁定 12~15 张**——首发消费口不空转，见 04 文档 3.1） |
| 武学渊源 | 8~10 条（单人 4 条（+待补）+ **联机专属 1~2 条**，其余联机渊源第 2 批扩充） |
| 主线 | 15~18 波，首领每 5 波，3 难度档（普通/困难/地狱——地狱保留首发，2026-10-15 定） |
| 三选一 | 常规 + 首领后高级池，升层质变，去重权重 + 谱系引导 |
| 奇遇 | 个人奇遇 6~8 条（增益/挑战/彩蛋三类）；**全房奇遇移至第 2 批**（2026-10-15 评审瘦身） |
| 无尽模式 | 主线后续波，三次方血量公式起步（旧图公式参考） |
| 爽感表现 | **飘字、暴击/渊源播报、精英波与首领结算演出——M3 起即为正式内容**（可简版特效，但必须在场；2026-10-15 提前，见 M3 验收） |
| 名望经济 | 局内产出 + 永久解锁（武学/外观）+ 一次性消耗 3~4 种 |
| KK 存档 | 04 文档 4.1 协议全量（版本/名望/解锁/成就位/最高进度/领取标记） |
| 联机 | 1~4 人各守一路、武学互赠、联机专属渊源 |
| 付费点 | 进场特权（首发先做 1 档验证转化，含最高档乘法项）+ 全屏支援令（主力付费点）；商品形态表见 04 文档 3.3 |
| 平台 | KK 对战平台首发；本地双开验证同步 |

## 四、明确不做（负面清单）

- 装备/神器/熔炼系统（旧图教训：第二套养成干扰塔 build）；
- 付费 RNG 抽取（D6 护栏 3）；
- 英雄双轨成长（等级/装备/绝学物品，已由镇派弟子 D12 替代）；
- 无限资源产出类付费（永久每秒金币，永久禁止）；
- 跨局保存局内快照（指南 §8.1）；
- PvP、玩家间金币交易。

## 五、里程碑映射（指南 §11 细化）

| 里程碑 | 内容 | 验收 |
|--------|------|------|
| M0 工程环境 | TS 入口链、日志、Frame 最小面板、双开同步短命令、KK 测试 Key 读写 | 指南 §4.1 六条最低验收 + 实机显示版本号 |
| M1 最小波次 | 四区路线进入外环后永久无碰撞循环、1种敌人、独立开波倒计时、本路80只红字警告/连续20秒超限失败、首次出怪前7秒生成常驻定向门、按在场人数显示的可收起黑底HUD | 击杀+取消注销+存活=已生成；失败/重测旧代次不再刷怪或建门；危险解除使旧判负计时失效 |
| M2 建造与弟子 | 建造事务、占地、金币、少林 4 线进阶、镇山阻挡（D13 技术验证） | 双开建造一致、阻挡/重生正确、失败回滚无残留 |
| M3 完整单局 | 三选一、武学装配、15~18 波、3 难度、首领、胜负结算、爽感表现（飘字/播报/精英与首领演出） | **零测试命令完整单局**（MVP 核心验收）+ 爽感验收：任意 30 秒内有事可做、峰值密度每 3~4 波一次 |
| M4 联机 | 1~4 路、互赠、联机专属渊源（1~2 条）、玩家离开 | 双开/四开波次随机结算一致 |
| M5 局间 | 名望结算、解锁池、一次性消耗、存档协议、付费点最小集合（1 档进场令 + 支援令） | 跨局读取生效 + 真实 KK 房间复验（04 文档 4.3） |
| M6 内容表现 | 3 门派全量、奇遇全量、特效音效升级（简版→完整）、性能压力 | 30 分钟长局无泄漏、波次间对象回落 |

## 六、关键风险与对策

| 风险 | 对策 |
|------|------|
| 普通弟子「不被索敌」的 WC3 实现不确定（D13） | M2 之前先做技术验证切片；若受阻，回退方案 = 全定身式阻挡（03 文档 2.3 备选） |
| 武学联动在 1.27 无 JAPI 环境下的特效表现 | 特效降规格预案：粒子替代全屏模型；UI 遵循指南 §7 硬边界 |
| 三选一/奇遇的同步随机一致性 | 固定种子调试 + 双开对账测试命令（指南 §5.3） |
| KK 存档额度/限频与本地模拟不符 | 04 文档 4.3 复验清单，本地与真实房间结论分开记录 |
| 付费强度失衡引发口碑问题 | D6 护栏：效果封顶 + 文案不锁死数字 + 配置热修 |
| 数值平衡工作量（3 门派 × 13 单位 × 武学池） | 全部 xlsx 配置 + 木桩测试命令 + 按波次自动验收 |
