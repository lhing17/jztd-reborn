# 01 · 项目定位

> 版本：v0.1（草稿） · 2026-10-14
> 状态：设计讨论稿，未定稿；改动需同步更新「已定决策」一节

## 一、项目背景

本项目是《决战TD》（武侠题材 War3 塔防）的太阳编辑器重构版，保留武侠题材，玩法与数值全部重新设计。原地图的失败教训是本项目最重要的设计输入。

### 1.1 原地图失败原因复盘

| # | 失败原因 | 具体表现 | 结构性教训 |
|---|----------|----------|------------|
| 1 | 塔设计重复、内容成本失控 | 每门派五六种技能，按等级拆成多种塔（初级弟子韦陀拳Lv1、中级Lv2、高级龙爪手Lv1/Lv2……）；塔只有纵向数值、没有横向差异；解锁高级塔后初级塔完全作废；新增一个门派要重做整套换皮塔 | 深度必须来自「组合」，不能来自「同技能换数字」；初级内容必须终身有用 |
| 2 | 数值不可修复 | 各门派严重不平衡；付费物品投放了过多资源，发现过强后无法修改 | 一切数值必须配置驱动、可随时热修；付费与强度必须彻底分离 |
| 3 | 设计理念落后于市场 | 发布时塔防流行抽卡+羁绊，古法设计没有竞争力 | 随机获取 + 组合联动带来的局局新鲜感，是当下塔防的入场券 |
| 4 | 系统堆砌（复盘补充） | 旧 TODO 可见：武器、心法、天赋、挑战怪、境界突破、装备、羁绊、塔罗牌、熟练度、签到……各系统互相独立堆叠，没有统一骨架 | 新设计必须一个骨架承载所有系统，宁缺毋滥 |

### 1.2 本次重构的目标

- **保留**：武侠题材、门派选择、弟子即塔的题材表达。
- **重做**：塔的结构体系、数值与经济、单局节奏、随机与组合玩法、存档与付费边界。
- **交付标准**：玩家不输入任何测试命令即可完成「选门派 → 建塔 → 打完主线 → 爽到 → 奖励可靠入档 → 再开一局」。

## 二、产品定位

**平台判断（来自 KK 平台负责人的用户分析）：KK 对战平台用户来 War3 RPG 地图是为了体验其他游戏给不了的「爽感」，不是来玩一个「设计正常的游戏」。**

因此本项目的优先级排序：

1. **爽感是第一产品目标**；平衡、深度、长线都是用来延长爽感周期的手段，不是目的。
2. 主线是「把爽完整交付一遍」的旅程，通过率应偏高；挑战与数值验证放在无尽模式和高难度档。
3. 决策（三选一、进阶分支、武学搭配）必须存在，但只服务于「这爽是我选出来的」；选错能快速纠偏，不惩罚尝试。
4. 失败成本低：死了马上能再爽一把。

### 2.1 爽感设计原则

| 原则 | 含义 | 落地要求 |
|------|------|----------|
| 雪球滚得快 | 前 3 分钟必须出现第一个 build 成型瞬间 | 经济慷慨；第 1 波结束即首次三选一 |
| 反馈密度拉满 | 大数字飘字、暴击、连锁、全屏特效、收割式击杀反馈 | 飘字与特效从 MVP 起就是正式内容，不是后期美化 |
| 峰值有对比 | 先被压住再爆发，比全程平推更爽 | 每章安排 1~2 次压迫→反打 |
| 数值敢夸张 | 联动倍率给足，「别的游戏给不了的爽」往往就是不克制的那一下 | 平衡性微调让位于爽感表现 |
| 画面主风格 | **满屏阵势式为主**（万剑齐发、剑气纵横、阵法齐动的场面感），**个人英雄式为峰值点缀**（首领战、大招弟子的一击决胜） | 塔防的单位数量天然适合阵势式；英雄式只用于高潮时刻 |

## 三、核心技术约束

技术栈与环境基线以《太阳编辑器塔防AI协作开发指南》为准（War3 1.27 + 太阳编辑器 + TypeScriptToLua + YD Lua + KK API，无内置 JAPI 基线）。对设计文档的直接约束摘录：

- 一切玩法状态须同步，UI 本地分支不改状态；
- 波次是显式状态机；敌人由统一服务登记；
- 存档只存轻量局间数据（货币、解锁、成就、最高进度），不存局内快照；
- 数值全部配置驱动（config / xlsx），版本更新即可热修。

## 四、已定决策

| # | 决策 | 结论 | 日期 |
|---|------|------|------|
| D1 | 塔的结构体系 | 三层结构：**弟子单位**（每门派 3~4 种，承担角色定位：阻挡/单体输出/范围输出/辅助）＋ **进阶树**（初级弟子是所有路线的起点，高级弟子由进阶而来，初级塔终身有用）＋ **武学层**（全局复用的秘籍资产，装给满足条件的弟子） | 2026-10-14 |
| D2 | 技能表达方式 | 武学是单位的身份与可组合资产，不是按等级拆塔的零件；新增门派成本 = 4 个单位 + 1 棵进阶树 + 几张武学卡 | 2026-10-14 |
| D3 | 随机获取 | 不用付费抽卡；改为**局内三选一**（rogluelite draft），每波结算触发，首领波后升级为高级三选一 | 2026-10-14 |
| D4 | 组合联动 | 羁绊改为**武学渊源**：特定门派/武学组合在场上触发行为级联动（非纯数值），配置表驱动 | 2026-10-14 |
| D5 | 局间成长 | KK 轻量存档存「已解锁武学/门派池、最高波次、成就、局外货币」；通关解锁新内容，给复玩理由 | 2026-10-14 |
| D6 | 付费边界 | 付费只卖外观、便利、内容体验；**爽感本身不标价**，不卖任何影响单局强度的资源 | 2026-10-14 |
| D7 | 单局时长 | 主线 20~30 分钟（按 25 分钟中值设计）+ 可选无尽模式 | 2026-10-14 |
| D8 | 联机定位 | 支持 1~4 人；以单人体验为主设计基线，双人其次，四人必须可用 | 2026-10-14 |
| D9 | 难度结构 | 主线多难度档（普通=爽就完事 / 困难=有压迫感 / 地狱=硬核），无尽模式承接长线挑战 | 2026-10-14 |
| D10 | 爽感画面风格 | 满屏阵势式为主，个人英雄式为峰值点缀 | 2026-10-14 |
| D11 | 奇遇事件系统 | 旧「智慧球+挑战怪」升级为奇遇事件：每 2~3 波触发一次，形式为「随机事件 + 特殊三选一」，全部局内免费产出、配置驱动、武侠叙事包装 | 2026-10-15 |
| D12 | 镇派弟子（英雄位） | 保留 1 个英雄位单位：从进阶树终极分支长出，每玩家限 1；不引入第二套成长（无等级/装备/绝学），强度全部来自进阶投入与所配武学；微操上限 = 1 主动大招 + 站位 | 2026-10-15 |
| D13 | 弟子生存规则 | 混合制：惊鸿/覆雨/回春线与镇派弟子无敌；仅镇山线有血量可被攻击。阻挡 = 咽喉点部署 + 嘲讽定身（不用身体卡位）；每阻挡位限拦数量、溢出绕行；镇山死亡原地打坐重生不永久损失 | 2026-10-15 |
| D14 | 命名策略 | 全部使用原创名：人名、武功名、门派相关文案均不使用金庸人名/武功名；现有名均为占位，后续统一文案风格 | 2026-10-15 |
| D15 | 阴阳属性 | 武学阴阳标签（渊源计数用）与门派阴阳阵营（装配资格用）解耦：少林、丐帮=阳，武当、峨眉=阴；门派武学限本门派、通用武学不限装配、绝学限阵营（三选一池按资格过滤）；通用武学全带阴阳标签保障单人可组阴阳渊源；武当太极系武学带太极标签同时计阴阳，为联机组合枢纽 | 2026-10-15 |
