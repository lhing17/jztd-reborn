# 02 · 核心玩法与单局流程

> 版本：v0.1（草稿） · 2026-10-14
> 前置文档：01-项目定位.md（决策 D1~D10 本文直接引用）
> 状态：设计讨论稿；波次表与数值均为占位骨架，待 03 号文档细化

## 一、玩法概述

一句话：**选门派，收弟子，配武学，组渊源，守住主线，然后无尽。**

```text
进入游戏
  → 选择门派（获得该门派建造者）
  → 建造弟子（初级弟子是所有路线的起点）
  → 弟子进阶（进阶树分支选择）
  → 每波结算：武学三选一 → 装配给弟子
  → 门派/武学组合点亮「武学渊源」
  → 打完 15~18 波主线 → 最终首领
  → 结算 + 局间奖励入档
  → 可选：进入无尽模式，build 堆到荒诞
```

玩家操作的核心决策只有三个，且全部服务于「这爽是我选出来的」：

1. **建谁**（弟子单位与站位）；
2. **走哪条路**（进阶树分支）；
3. **拿什么武学、给谁配**（三选一与装配）。

## 二、单局结构

按 25 分钟中值设计：主线 **15~18 波**，每波周期 **80~100 秒**，每 5 波一个首领波。

### 2.1 爽感时间轴

| 时间 | 阶段 | 玩家体验 | 设计任务 |
|------|------|----------|----------|
| 0~3 分钟 | 开局 | 建第一批弟子，打完第 1 波，第一次三选一 | 快速给出第一个成型瞬间 |
| 3~10 分钟 | 成型期 | 进阶树展开、第一条武学渊源点亮、开始割草 | 每波都有可见变强 |
| 10~20 分钟 | 爆发期 | 武学联动成型；精英波施压再反打 | 1~2 次「先被压住再爆发」 |
| 20~28 分钟 | 高潮 | 最终首领，build 全力释放 | 终局大爽点 + 结算演出 |

### 2.2 三选一节奏

| 时机 | 类型 | 内容 |
|------|------|------|
| 普通波清场后 | 常规三选一 | 普通武学 / 经济选项（金币、修为）/ 弟子相关 |
| 首领波后 | 高级三选一 | 稀有武学 / 门派专属武学 / 高阶弟子进阶资格 |

一局总计 15~20 次选择，build 从起手到完全成型正好铺满主线。

**三选一规则草案：**

- 每次从池中随机 3 项，玩家选 1；可花金币刷新 1 次（刷钱出口，防脸黑）；
- 武学分品质（普通/稀有/门派专属），高级池仅首领后开启；
- 武学可升级：重复获得同种武学自动升层（层数给质变，不只是数值）；
- 武学有装配条件（限门派 / 限弟子定位 / 限兵器类型），装配与更换免费，鼓励尝试；
- 三选一的随机在同步逻辑中消耗（遵循开发指南 §5.3）。

### 2.3 奇遇事件（D11）

「计划外的爽」：三选一是计划内的成型节拍，奇遇是穿插其间的意外惊喜，两者交替构成完整爽感节奏。由旧图智慧球 + 挑战怪两个系统合并升级而来。

| 项 | 规则 |
|----|------|
| 触发节奏 | 每 2~3 波一次，主线 15~18 波共约 6~8 次；固定时间轴 + 事件池随机 |
| 形式 | 优先「随机事件 + 特殊三选一」：奇遇触发时弹出一次特殊三选一，玩家选择后结算 |
| 内容池 | 增益类（天降横财=下波金币翻倍、绝世高手路过=随机一塔武学升层、黑市商人=本局刷新免费）；挑战类（精英拦路=花金币召唤挑战波，掉稀有武学）；彩蛋类（全场内力回满、随机开放隐藏武学） |
| 叙事包装 | 武侠说书人式播报，事件全部有剧情名目；配置驱动，可随版本扩充 |
| 边界 | 全部局内免费产出（D6）；随机在同步逻辑消耗；操作只发同步短命令，播报与特效走本地分支 |

## 三、波次与敌人（占位骨架）

主线 15~18 波，敌人按职能分四类，与难度档正交：

| 职能 | 设计意图 | 爽感作用 |
|------|----------|----------|
| 普通怪 | 经济与 build 进度的燃料 | 割草主体 |
| 快速怪 | 惩罚无控制 build | 制造小压力 |
| 耐久怪 | 惩罚单体 build，抬范围输出价值 | 血条消失的快感载体 |
| 精英/首领 | 机制载体（分波次引入能力） | 压迫→反打的峰值设计对象 |

- 每 5 波一个首领（第 5/10/15 波，第 15 波或第 18 波为最终首领）；
- 精英怪带**敌人侧词缀**（复用旧 词缀.txt 思路：疾速、破防、狂化等），作为机制变化来源；
- 敌人到终点扣基地生命，漏怪结算一次；敌人属性、波次计划全部配置驱动（xlsx）。

## 四、难度档

| 难度 | 定位 | 敌人强度 | 奖励 |
|------|------|----------|------|
| 普通 | 「爽就完事」，主线通过率应偏高 | 基线 | 基础局间货币 |
| 困难 | 有压迫感，需要认真组 build | 普通 × 系数 | 更多货币 + 解锁项 |
| 地狱 | 硬核挑战 | 显著加压 | 稀有解锁 + 最高进度记录 |

难度影响敌人数值与波次计划，不影响 build 池——「通关更高难度解锁新武学/门派」是局间成长的主轴。

## 五、无尽模式

- 主线通关后无缝续波，敌人按波次持续膨胀，每 10 波一个超级首领；
- 三选一继续，build 可堆到荒诞强度——无尽模式的卖点是「看数字崩坏」；
- 局间存档记录最高波次；未来可扩展无尽排行榜；
- 无尽中允许「重置站位」类功能，把 25 分钟主线沉淀的 build 带进长跑。

## 六、联机（1~4 人）

玩家分布预期：单通最多、双人次之、四人必须可用。设计原则：**以单人体验为基线，人数只改变规模，不改变玩法结构。**

初步方案（待讨论）：

- 地图按 4 路设计，玩家人数 = 启用的路数（单人 1 路，双人 2 路……）；
- 每人独立金币、独立基地生命、各自失败互不拖死（多人翻车不连带）；
- 联机专属爽感：武学可互赠/互换、跨路渊源联动（你的少林配我的武当）；
- 同步边界严格遵循开发指南 §5：建造、扣钱、波次、三选一、随机全部同步，UI 只发短命令。

## 七、爽感表现规范

| 项 | 规范 |
|----|------|
| 主风格 | 满屏阵势式：成建制的剑气、掌风、阵法齐动，单位数量转化为场面 |
| 峰值点缀 | 个人英雄式：首领战与镇派弟子大招的单点爆发、一击决胜镜头感（D12） |
| 数值反馈 | 大数字飘字常驻；暴击、连锁、渊源触发有专属播报与音效 |
| 收割感 | 连续击杀有递增反馈（连杀播报/音效层叠） |
| 结算演出 | 首领死亡必有大结算：全屏反馈 + 掉落展示 + 高级三选一 |
