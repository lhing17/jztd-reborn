# 12 · 工程与框架笔记

> 代码边界、框架结论与实测证据。本地模拟与真实 KK 房间结论**分开记录**。

## 12.1 工程基线（2026-10-15 M0）

- 白板地图：吉森用太阳编辑器创建，仅含太阳 TS 开发框架（`map/game_root/`）。
- 启动链：`solar_boot.lua` → `App.lua` → `App.ts`（延迟 0.01s，`isEmbedJapi` 分支）→ `StateConfigInit` → 框架状态 → `StateInit` → 本项目模块。
- 业务代码入口：`src/game/`（config / core / ui / test，按指南 §三逐步扩充）。
- 日志：框架全局 `log`（`@sl-wc3/Log`，写文件）；本项目分类封装 `GLog`（普通/战斗/同步/波次/存档五类开关）。
- 版本三件套：`GameConfig.version / configVersion / archiveVersion`，显示于左上角 DevPanel 与 `-jt v`。

## 12.2 框架 API 备忘（已读源码确认）

- `SyncUtil.syncData(key, data)`（可异步发送）/ `SyncUtil.onSyncData(key, fn)`（fn 收 `triggerPlayer, data`，玩家身份取自同步事件）。
- `ArchiveUtil.set/get(player, key, value)`：桶式哈希存档，自动 64 字符切片；`set` 默认立即上传。
- `BaseUtil.runLater / onTimer / getGameTime`：计时器规范按指南 §6.2。
- `se.onPlayerChat(文本, cb, exactMatchOnly=true)`：精确匹配。
- Frame：`createBackDrop/createTEXT/createTEXTBUTTON`；背景必须 `setIgnoreTrackEvent(true)`（等价 DzFrameSetIgnoreTrackEvents）；禁止 `Frame.setLevel`。
