# 11 · 测试命令速查

> 游戏内聊天输入。命令前缀 `-jt`（GameConfig.debugCmdPrefix）。
> 测试命令统一在 `src/game/test/`，复用正式服务，不另写旁路玩法。

## M0 命令

| 命令 | 前置状态 | 作用 | 预期结果 | 清理 |
|------|----------|------|----------|------|
| `-jt v` | 任意 | 显示版本/配置版本/存档版本/调试标志 | 上屏一行版本信息 | 无 |
| `-jt view` | 调试局 | 只读检查环境初始化与视野开关，不改变状态 | 战争迷雾=false、黑色遮罩=false、环境初始化=true | 无 |
| `-jt sync` | 单人或双开 | 发送同步探针短命令 | 所有客户端上屏「触发玩家=XXX」且玩家名一致 | 无 |
| `-jt arch` | 任意 | KK 测试 Key 读写（`jzr_test_v1`） | 首次：写入成功；重开一局后：读到上次写入的值 | 无（测试 Key 可留） |

## 地形显示检查

太阳编辑器直接运行，点击小地图查看四区，检查地板、道路、树木和颜色；确认没有黑幕、缺纹理及通道堵塞。镜头与远景雾自动初始化；`-jt view` 仅查询开关，不能替代载入结束首帧至 10 秒、切出再切回的画面检查。没有临时改地形的 `-jt terrain` 命令。
