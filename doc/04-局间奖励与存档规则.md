# 04 · 局间奖励与存档规则

> 版本：v0.1（草稿） · 2026-10-15
> 前置文档：01-项目定位.md（D5/D6/D8）、02-核心玩法与单局流程.md
> 约束：太阳编辑器塔防AI协作开发指南 §8（轻量存档边界、63 字符保守上限、真实 KK 复验清单）

## 一、设计原则

1. **存档只存局间轻量状态**：货币、解锁、成就、最高进度、领取标记——不存局内塔/波次/敌人快照（指南 §8.1）；
2. **解锁改变「池子」而不是「强度」**：解锁项扩展 build 多样性（新门派、新武学、新事件），不投放原始数值；
3. **一切收益来自玩法**：付费只买外观/便利（D6），不写入任何影响强度的存档字段；
4. **幂等与可迁移**：协议带版本号，升级走小型迁移函数；同一局奖励带局次令牌，防重复结算。

## 二、局外货币：名望

| 项 | 规则 |
|----|------|
| 名称 | **名望**（2026-10-15 定名；与旧图「珍稀币/积分」区分，珍稀币留在局内） |
| 性质 | 局外累积货币，只增不减（无消耗型衰减） |
| 作用 | 双消费口：永久解锁 + 一次性消耗（见第三节）；同时作为玩家资历的展示值 |

### 2.1 产出（单机单局）

| 来源 | 名望 | 说明 |
|------|------|------|
| 波次推进 | 每波 +2 | 失败局也按到达波次结算，不打断成长感 |
| 难度通关 | 普通 30 / 困难 60 / 地狱 100 | 主线通关一次性 |
| 首通奖励 | 各难度首次通关额外 +50 | 一次性，领过即灭（领取标记存档） |
| 无尽深度 | 每 10 波 +10（通关后计入） | 长线玩家主收益 |
| 奇遇与挑战 | 挑战类奇遇成功 +3~5 | 鼓励参与 |
| 组队加成 | 通关奖励 +10%/名队友（上限 +30%） | 鼓励联机，不卖强度；**存活校验**：队友须存活至该玩家通关波次之后才计加成（防多开挂机刷，见 05 威胁模型） |

**防刷约束**：同一难度重复通关只按「通关 10 + 波次」计，首通不重复；收益全部配置驱动，可热修。

### 2.2 平台福利系统（KK 运营导向，重要）

KK 平台要求/建议作者向玩家赠送大量福利以刺激游玩与消费。名望的大宗额外来源将来自平台化福利系统（**后续版本接入**，均为一键领取式）：

| 系统 | 说明 | 批次 |
|------|------|------|
| 地图等级奖励 | 按累计游戏时长提升地图等级，每级领取名望 | 首发版本后 |
| 每日任务 | 如「通关任意难度 1 次」「击杀首领 3 个」 | 首发版本后 |
| 每周/每月任务 | 长线目标，奖励更丰 | 后续 |
| 签到奖励 | 连续登录阶梯奖励 | 后续 |

**设计推论（2026-10-15 确认）**：福利系统会让名望供给远大于单机产出，货币必然通胀——因此消费口**不能只做永久解锁**，必须保留**一次性消耗**作为常驻泄洪阀（见 3.2）。调控手段：全部产出配置化可热修；消耗口随版本持续扩充。

## 三、名望消费：永久解锁 + 一次性消耗

### 3.1 永久解锁（改变「池子」）

| 类型 | 示例 | 定价节奏（2026-10-15 定） | 批次 |
|------|------|--------------|------|
| 武学入池 | 武学扩展包 ×N、绝学解锁 | 40 名望/张（首解锁约 1 局可达） | 持续投放 |
| 奇遇事件 | 新奇遇剧情线 | 50 名望/条 | 持续投放 |
| 门派 | 丐帮（第 4 门派） | 300 名望（约 4~5 小时游戏时长，中期目标） | 第 2 批 |
| 外观 | 弟子皮肤、建造者皮肤、播报皮肤 | 名望或付费（D6 边界内的付费点） | 持续投放 |

**首发内容归属（2026-10-15 补定，防局间成长空转）**：首发武学池 ~30 张中，**默认解锁 15~18 张**（保证第一局 build 完整），**名望锁定 12~15 张**（以高价值通用武学与绝学为主）；首批可解锁内容深度做到 **600~800 名望（约 6~8 小时游戏时长）**，让玩家第一局打完就有明确的存钱目标。每张武学的首发归属在配置注册表中标注（默认/名望/难度解锁）。

### 3.2 一次性消耗（本局生效，通胀泄洪阀）

开局前可选购买，每次消耗名望，**只对本局生效**（2026-10-15 定：接受一次性便利消费）：

| 消耗品 | 效果 | 定价（占位） |
|--------|------|--------------|
| 保送弟子 | 开局白送 1 个入门弟子（自选线别） | 15 名望 |
| 开局行囊 | 开局金币 +300 | 10 名望 |
| 奇遇罗盘 | 本局奇遇三选一可重掷 1 次 | 10 名望 |
| 重修令 | 本局免费拆塔全额退款 1 次 | 15 名望 |

约束：同时最多带 2 个消耗品进局（防叠加）；消耗品只影响体验与小节奏，**不提供任何局内无法获得的独占内容**；定价全部配置化，随福利系统上线后的通胀情况热修。

**设计红线**：解锁项与消耗品必须通过「配置注册表」登记（稳定 ID + 类型 + 批次）；永久解锁不得投放原始强度，外观类与功能类分表管理。

### 3.3 付费点（2026-10-15 定，D6 修订配套）

市场判断：War3 玩家群体（30~40 岁为主）为皮肤付费的意愿低，且 War3 皮肤制作成本高；**付费必须带来可感知的变强**（更高难度通关、更深无尽）。因此付费点以强度与确定性为主：

| 类别 | 内容 | 护栏 |
|------|------|------|
| 进场特权（主付费点） | 三档进场令：开局额外金币/珍稀币、三选一刷新次数、高级池初始权重 | 效果封顶、配置热修 |
| 局内应急道具 | 单局购买：全屏支援令（伤害/定身 ×N 次）、金币包 | 次数封顶、每日购买上限 |
| 成长加速 | 名望加成卡（+50% 名望，限时/限局数） | 只加速进度，不卖独占内容 |
| 确定性道具 | 三选一锁定卡、奇遇重掷令 | 卖「不脸黑」，不卖数值 |
| 便利/外观 | 托管、自动进阶、皮肤 | 次要付费点，低优先级 |

**四条护栏（继承旧图教训，写死）**：

1. **商城文案只承诺效果方向、不锁死具体数值**——旧图教训的真面目：数值并非技术不可改，而是商城说明承诺了数字、改动即违约被投诉。因此商城说明写「开局获得额外金币」而不写「+300」，具体数值进配置表并随版本平衡（必要时说明页声明「效果随版本调整」）；
2. 每效果设硬上限，不卖无限资源产出（永久每秒金币类永久禁止）；
3. 不做付费 RNG 抽取；
4. 免费玩家全部内容可达——付费是加速与量变，不是质变门槛。

**公平性预留**：若未来开放无尽排行榜，进场特权状态须标注或分组，避免付费强度污染排行。

**技术实现**：付费判定沿用 KK 商城接口（`HasMallItem` 类）运行时读取，商城道具只作为开关，效果数值一律读配置表。配置化是「可调」的必要条件，而护栏 1（文案不锁死数字）才是「敢调」的充分条件——两者缺一不可。

## 四、KK 存档协议

### 4.1 键值设计

项目前缀 `jzr_`（项目正式名确定后替换）。保守按单 Key/Value ≤63 ASCII 字符设计（指南 §8.3，真机复验后再放宽）：

| Key | Value | 说明 |
|-----|-------|------|
| `jzr_ver` | 协议版本号，如 `1` | 迁移函数的锚点 |
| `jzr_fame` | 名望总额 | 整数 |
| `jzr_unlock` | 解锁 ID 列表，逗号分隔 | 超长按 `jzr_unlock1/2/…` 分片；ID 用短编码（如 `GQ01`） |
| `jzr_achv` | 成就位图（base64） | 成就编号位 |
| `jzr_best` | 最高通关难度+最高无尽波次，如 `3:87` | 进度展示 |
| `jzr_claim` | 一次性奖励领取标记位图 | 首通奖励等 |

**校验**：写入时对 value 做校验和混编（简单自校验，防手改档异常）；读取失败按空档处理并记日志，不阻塞进游戏。

### 4.2 写入时机与防重复

- **只在局末结算与领取时写入**，不按秒保存（指南 §8.2）；
- 同一局奖励计算先在同步状态内完成，局末确认后一次写入；带**局次令牌**，重试/重复点击不产生重复入账；
- 写入后立即回读，向玩家显示「存档成功/失败」，失败给补偿提示（名望入账延迟到下次进游戏补发）；
- 平台写入慢不阻塞 War3 主流程：写入放结算界面后台，玩家可继续点「再来一局」；
- 调试命令只操作 `jzr_test_*` 前缀的测试 Key，**严禁触碰正式存档**（指南 §9.6）。

### 4.3 真实 KK 复验清单（上线前必做）

Key/Value 长度上限、总额度与分项额度、写入频率限制、失败返回值语义、跨局读取、掉线/房主离开时的写入行为、测试服与正式服数据是否共享——本地模拟器结论与真实房间结论**分开记录**（指南 §8.3）。

## 五、多人经济规则建议方案（定 01 遗留问题 2）

| 项 | 建议 |
|----|------|
| 金币 | **独立**——各自建造各自经济，互不拖死 |
| 基地生命 | **独立**——一名玩家失败不影响他人继续（失败者可旁观或提前退出，奖励按个人波次结算） |
| 分路 | 玩家人数 = 启用的路数（1 人 1 路 … 4 人 4 路），各守各路，敌人从各自路口进 |
| 资源共享 | 金币不可交易（防工作室/防破坏经济，旧图也禁给钱）；**武学可互赠**——每局每人限赠 1 次、限 1 张，受赠方须满足装配资格 |
| 协作爽点 | 跨路武学渊源（佛光剑影等联机专属）、武学互赠、组队名望加成 |
| 玩家离开 | 离开后其路口停刷（或怪物按离线玩家路数重新分配），其余玩家继续；存档按离开时已达成结算 |
