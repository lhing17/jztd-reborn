## 一、结构总则

```text
门派（选 1）
  └─ 弟子线 × 4（每条线 = 一个角色定位）
       入门弟子 → 精英弟子 → 成名弟子      （进阶树，纵向在同一条线内完成）
  └─ 镇派弟子 × 1（D12：进阶树之上，独立于四线）
  └─ 门派武学 × 若干（武学层，全局可获取，装配给满足条件的弟子）
```

三条铁律（继承 D1/D2/D12）：

1. **纵向只发生在同一条弟子线内**（入门→精英→成名），跨线不互通——初级弟子终身有用，因为每条线都必须从入门建起；
2. **横向深度全部来自武学层**：武学是全局资产，限门派/限定位/限阴阳属性装配，重复获得升层质变；
3. **镇派弟子是唯一英雄位**：无独立成长系统，强度 = 进阶投入 + 所配武学。

## 二、弟子定位与通用规则

### 2.1 四条弟子线（每门派相同骨架，风格由门派赋予）

| 线 | 定位 | 职责 | 关键属性 |
|----|------|------|----------|
| 镇山线 | 阻挡 | 咽喉点拦截、聚怪，为范围武学创造输出窗口；**唯一可被攻击的弟子** | 生命、护甲、反震/聚怪特性 |
| 惊鸿线 | 单体输出 | 点杀精英/首领，吃攻速与暴击 | 攻击、攻速、破甲 |
| 覆雨线 | 范围输出 | 清群怪主体，吃武学联动 | 范围伤害、触发类武学频率 |
| 回春线 | 辅助 | 治疗/护盾镇山弟子、增益友军、debuff 敌人 | 治疗量、光环、内力循环 |

### 2.2 通用规则

- 占地：每弟子 1 格；人口 = 弟子数 + 镇派弟子占 2；
- 进阶在同线内逐级进行，进阶保留所配武学（武学跟弟子不跟格子）；
- 出售退款：按累计投入 × 70%（待定），占地与人口即时释放；**退款比例随波次递减**（如 100%→70%→50%，数值待定），防每波卖光重配套利（2026-10-15 评审修订）；
- 所有造价/属性/进阶费全部进 xlsx 配置，版本可热修（D6 的配套保障）。

### 2.3 生存与阻挡规则（D13）

核心前提：**普通弟子无敌，阻挡是镇山线的专属职能**，兼顾割草流畅与武侠张力。

| 规则 | 内容 |
|------|------|
| 生存划分 | 惊鸿/覆雨/回春线 + 镇派弟子无敌（建筑化处理）；仅镇山线有血量、可被攻击 |
| 阻挡实现 | 镇山弟子只能部署在路径旁的**阻挡位**（咽喉点）；敌人到达后被嘲讽定身、原地攻击它——**不用身体碰撞**，规避 WC3 卡位/寻路整类问题 |
| 移动节奏 | 敌人仅在阻挡点停留，其余路段行军不受影响；波次时长 = 行走进度 + 阻挡延时（每点设上限），总时长可控 |
| 堆怪上限 | 每阻挡位限拦 M 个，溢出绕行——性能保险 + 天然漏怪压力阀；聚怪供覆雨线一锅端（「先聚后爽」） |
| 死亡规则 | 镇山弟子死亡原地打坐重生（10~20 秒可配置），阶位越高血越厚、重生越快；永不永久损失 |
| 治疗联动 | 回春线治疗对象 = 镇山弟子；镇山×回春与「佛光剑影」渊源因此成立 |
| 技术待验证 | WC3 中普通弟子「不被敌人索敌」的具体实现（无敌标记 vs 蝗虫 vs 建筑化）列入 M0/M1 验证项 |

**软控制通道与首领机制（2026-10-15 补，回应独立评审 P0-3「镇山隐性必配」）**：

- **软控制**：控制类武学（点穴手=概率定身、狮吼功=震慑等）对未入阻挡位的敌人同样生效——纯输出 build 可以在小怪到达阻挡位前靠控制链吃掉一截，「无镇山 = 完全拦不住」不成立；
- **首领阻挡失效期**：首领周期性强攻可使阻挡位短暂失效（如每 20 秒 5 秒失效期，数值待平衡）——给纯输出 build 在首领战留出生存空间，也让镇山 build 有「失效期保后排」的操作点；
- **设计承诺**：镇山是**主流解**（聚怪效率最高），不是**唯一解**；任何「四线必建某线」的结论若实测成立，按 2.1 裁剪线别而不是放任摆设。

**备选方案存档**：全无敌+定身场（镇山变超级减速塔，与武当重叠、张力弱）；全单位可攻击（经营压力大、与爽感定位冲突）。均不采纳。

## 四、武学层规则

### 4.1 品质与获取

| 品质 | 来源 | 第一版规模 |
|------|------|-----------|
| 通用武学 | 常规三选一池 | 10~12 张 |
| 门派武学 | 常规池（本门派权重高）+ 高级三选一 | 每门派 6~8 张 |
| 绝学（稀有） | 仅高级三选一 / 奇遇挑战类事件 | **首发 4 张**（2026-10-15 评审瘦身，与 06 一致），后续扩充至 6~8 |

### 4.2 装配规则

- 所有弟子**统一 2 个武学槽**（2026-10-15 确认，成名不额外加槽）；
- 装配限制三类型（2026-10-15 修订）：**限本门派**（门派武学）／**不限**（通用武学，任何弟子可学）／**限阵营**（绝学内功心法）；
- **阴阳标签与装配限制解耦**：阴阳标签只用于渊源计数，不构成装配门槛；
- 装配与卸下免费、即时生效，鼓励随 build 调整；
- 重复获得同种武学 → 自动升层；层数给质变（如「点穴手 Lv3：定身变群体」），不只是数值。

### 4.3 武学池示例

- 通用（不限装配，**全部标注阴阳**，见 4.4）：吐纳法（阴，内力回复）、铁布衫（阳，受击减伤）、点穴手（阴，概率定身）、漫天花雨（阴，攻击分裂）、狮吼功（阳，范围震慑）……（待扩充）
- 少林专属（限本门派，阳）：韦陀拳、龙爪手、拈花指、狮子吼
- 武当专属（限本门派，阴）：两仪剑法、神门十三剑、梯云纵、太极剑法（太极标签，见 4.4）
- 峨眉专属（限本门派，阴）：峨眉剑法、回风拂柳剑、佛光咒、素心剑诀
- 绝学（限阵营）：纯阳无极功（限阳派）、玄阴真经（限阴派）、独孤剑意（限阴派）、逍遥游（限阳派）

> 命名策略已定（2026-10-15）：**全部使用原创名**，不使用金庸人名/武功名。已有人物名（慧禅、云虚、玄静等）与武功名均为原创占位，后续统一由文案轮一遍命名风格。
>
> **三选一池构成**（2026-10-15 补定）：通用武学 + 本门派武学 + 绝学，**不出现其他门派武学**；且**按装配资格过滤**——绝学只出本阵营的，杜绝「看得到装不上」的死选项。

### 4.4 阴阳属性

「武学的阴阳标签」与「门派的阴阳阵营」是两个机制，用途不同：

**武学阴阳标签 = 渊源计数器**（两个用途）：

1. **渊源触发轴**：如「刚柔并济 = 阳武学≥2 + 阴武学≥2」，通用武学带阴阳标签后，单人玩家也能跨阵营组渊源（见 4.3 池构成）；
2. **风格 flavor**：标签与武学效果风格一致（阳=破甲反震爆发，阴=减速穿透连击）。

**门派阴阳阵营 = 装配资格 + 天生短板**（三个用途）：

1. **绝学修习资格**：内功心法限阵营——纯阳无极功仅阳派弟子可修，玄阴真经仅阴派弟子可练（武侠逻辑：体质不合强练会走火入魔）；
2. **敌人 counter-play 的天生短板**：未来敌人带「阴煞护体」类词缀（阴伤减免）时，阴派玩家的本门武学被克制，须靠通用武学/绝学补阳——门派阵营决定你的先天短板，通用武学是补板工具；
3. **风格锚点**：门派武学的阴阳标签与门派阵营强制一致，门派身份不模糊。

**阵营划分（2026-10-15 确认）**：

| 阵营 | 门派 | 风格 |
|------|------|------|
| 阳 | 少林、丐帮 | 外家至刚：破甲、反震、爆发 |
| 阴 | 武当、峨眉 | 内家柔劲：减速、穿透、卸力、连击 |

**特例：太极标签**——武当太极系武学同时计阴计阳。单人中太极桥梁非必需（通用武学已保障阴阳渊源可达），其价值在联机：武当成为多门派组合的渊源枢纽（符合太极阴阳合一设定）。

## 五、武学渊源（D4）

渊源由「场上存在的武学/门派组合」触发，全部为**行为级联动**（非纯数值），触发时有专属播报与特效。第一版 8~10 条，配置驱动。

**可达性三分法（2026-10-15 补定）**——渊源按单人可达性分三类，这是池构成（4.3）与渊源设计的共同约束：

| 类别 | 单人可达 | 说明 |
|------|----------|------|
| 门派内渊源 | ✅ | 本门派武学互相搭配，单人 build 核心目标 |
| 阴阳渊源 | ✅ | 靠通用武学的阴阳标签 + 本门派武学，跨阵营组合 |
| 跨门派渊源 | ❌ 联机专属 | 需其他门派弟子在场，是多人的专属爽点与组队动机 |

| 渊源 | 组合条件 | 行为效果 | 可达性 |
|------|----------|----------|--------|
| 刚柔并济 | 阳武学 ≥2 且阴武学 ≥2 | 阳命中被阴减速的目标 → 溅射；阴命中被阳破甲的目标 → 回内力 | 单人（通用武学） |
| 金刚伏魔 | 狮子吼 + 韦陀拳 同时装备 | 被眩晕的目标受伤害 +50%，眩晕结束触发余震 | 单人（少林） |
| 剑气纵横 | 两仪剑法 + 太极剑法 同时装备 | 剑气穿透 +2，穿透命中触发小范围剑爆 | 单人（武当） |
| 风回素心 | 回风拂柳剑 + 素心剑诀 同时装备 | 回旋剑气折返命中同一目标时，第二击必定暴击并附加连击计数 | 单人（峨眉） |
| 以柔克刚 | 太极线成名弟子 + 任意阳武学 ≥2 | 阻挡弟子受击时为攻击者叠「柔劲」，满层引爆定身 | 联机专属 |
| 佛光剑影 | 峨眉回春线 + 武当惊鸿线同时在场 | 治疗链溅射剑气：治疗溢出部分对周围敌人造成等量伤害 | 联机专属 |
| 百派来朝 | 场上 ≥3 个门派弟子 | 各门派镇派弟子大招冷却共享缩减（唯一数值型渊源，特例） | 联机专属（4 人） |
| （待补 1~2 条单人向） | | | |

> 注：跨门派武学在单人局中仅可能通过奇遇事件的特殊奖励获得一次性装配机会（机制待定）；常驻途径只有联机。

设计约束：每条渊源必须能通过「换武学/换站位」主动组出来——渊源是 build 目标，不是随机彩蛋。

## 六、镇派弟子细则（D12）

| 项 | 规则 |
|----|------|
| 解锁条件 | **任一弟子线升到成名**（2026-10-15 确认）+ 支付进阶资源（数额待平衡） |

| 表现 | 大招演出按个人英雄式规格：专属镜头感、全屏特效、说书人播报 |

## 七、已定事项与遗留问题

2026-10-15 讨论的 6 项已全部确认：

1. **门派数量**：MVP 3 门派（少林/武当/峨眉），丐帮第 2 批；
2. **武学槽**：统一 2 槽，成名不加槽；
3. **镇派弟子解锁**：任一线升到成名 + 资源；
4. **回春线作用域**：治疗镇山弟子 + 增益友军/削弱敌人；**砍掉基地生命缓回**（稀释漏怪代价；如未来需要，做成可选武学如「佛光咒：每波结束回复 1 点基地生命」）；
5. **命名策略**：全部原创名，文案后续统一风格；
6. **阴阳阵营**：少林/丐帮=阳，武当/峨眉=阴；太极系武学双属性（见 4.4）。

遗留问题（不阻塞开发，随平衡迭代）：

- 各弟子线造价/属性的具体数值（待 xlsx 配置与木桩测试）；
- 武学池最终名单与层数质变表（随数值配置阶段定，见 02/06 文档）；
- 丐帮门派整体设计（第 2 批内容）。
