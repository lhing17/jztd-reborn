# 决战TD·重生（jztd-reborn）

基于 War3 1.27 的武侠塔防地图，太阳编辑器 + TypeScriptToLua 重构（原《决战江湖TD》重构版）。
设计文档见 `doc/00~06`，开发规范见 `doc/太阳编辑器塔防AI协作开发指南.md`。

## 环境基线（开发指南 §2.2）

| 项 | 值 | 备注 |
|----|----|------|
| Warcraft III | 1.27 | 最终运行环境 |
| 太阳编辑器 | 待补充（吉森填） | 地图、物编、资源、TS 编译、打包 |
| Lua 目标 | 5.3 | `src/tsconfig.json` 的 `luaTarget` |
| 内置 JAPI | **无（硬约束）** | 若实际已购买需更新此项并复核 §7 硬边界 |
| KK 平台 | 首发平台；本地模拟器 + 真实房间双轨验证 | 存档结论分开记录（04 文档 4.3） |
| 最大玩家数 | 4 | 塔防惯例 1~4 人 |
| 联机验证 | 本地双开/四开 | 每里程碑必测 |

## 目录结构

```text
doc/                  设计文档 00~06 + 开发指南 + TODO/速查/笔记/HANDOFF
jass/                 旧版 jass 源码（复盘参考，不编译）
map/game_root/        太阳编辑器地图工程（src/ 业务源码，scripts/ 为生成物勿手改）
tools/                工具
```

## 构建模式

- **开发**：太阳编辑器打开工程直接编译测试（本地日志全开）；
- **测试**：打包 `jztd2.w3x` 本地双开验证同步；
- **发布**：slk 优化后上传 KK（`isDebug` 自动为 false，日志写文件不上屏）。
